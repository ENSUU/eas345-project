Note: everything from MP onward is a SEASON TOTAL, not a per-game average.
Divide by G before comparing teams.

| Column    | Meaning                                                                                             |
| --------- | --------------------------------------------------------------------------------------------------- |
| Rk        | Row number in the alphabetical listing — not a ranking                                              |
| School    | School name; " NCAA" is appended for teams that made the tournament                                 |
| G         | Games played                                                                                        |
| W         | Wins, overall                                                                                       |
| L         | Losses, overall                                                                                     |
| W-L%      | Win percentage, overall                                                                             |
| SRS       | Simple Rating System — average point margin adjusted for strength of schedule; 0 is an average team |
| SOS       | Strength of schedule, in points relative to an average schedule                                     |
| W.1 / L.1 | Conference wins and losses                                                                          |
| W.2 / L.2 | Home wins and losses                                                                                |
| W.3 / L.3 | Away wins and losses                                                                                |
| Tm.       | Total points the team scored all season                                                             |
| Opp.      | Total points opponents scored against them all season                                               |
| MP        | Total minutes played                                                                                |
| FG        | Field goals made                                                                                    |
| FGA       | Field goals attempted                                                                               |
| FG%       | Field goal percentage                                                                               |
| 3P        | Three-pointers made                                                                                 |
| 3PA       | Three-pointers attempted                                                                            |
| 3P%       | Three-point percentage                                                                              |
| FT        | Free throws made                                                                                    |
| FTA       | Free throws attempted                                                                               |
| FT%       | Free throw percentage                                                                               |
| ORB       | Offensive rebounds — the team's own missed shots it recovered                                       |
| TRB       | Total rebounds, offensive plus defensive                                                            |
| AST       | Assists — passes leading directly to a made basket                                                  |
| STL       | Steals — possessions taken from the opponent                                                        |
| BLK       | Blocks — opponent shots deflected                                                                   |
| TOV       | Turnovers the team committed                                                                        |
| PF        | Personal fouls committed                                                                            |
