# EAS 345 Data Science Project - March Madness Prediction Model 
**Group Members**: Justin Oakley, David Kim, and Kexin Cheng

## Summary
March Madness, the annual NCAA men's basketball tournament, is difficult to predict
because lower-seeded teams often upset higher-seeded opponents. We will build a prediction model in R that estimates the winner of each
tournament game from team statistics. We will collect regular-season statistics for the
2021–2025 seasons from Kaggle and Sports Reference, along with historical tournament
results. After cleaning and merging the data, we will train a logistic regression model on the
statistical differences between opposing teams. We will then use the model to complete a
full tournament bracket and to identify lower-seeded teams with strong upset potential. We
will validate the model by backtesting it on the 2022–2025 tournaments and measuring
game, upset, Final Four, and champion accuracy.
